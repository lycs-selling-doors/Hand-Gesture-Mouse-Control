# Gesture Desk 桌面操作指南

## 启动

在项目目录运行 `python -m pip install -r requirements.txt`，然后双击 `start_gui.cmd`，或运行 `python -m app.gui`。Windows 使用系统 WebView2；若提示缺少该运行时，请从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)安装。

界面、脚本和字体都来自本地，不依赖前端 CDN。模型缺失时，点击 GUI 中的「下载手部模型」，下载固定版本并验证 SHA-256。模型准备后可离线进行识别。

## 为不同姿势校准灵敏度

1. 点击「启动预览」。预览不会输出鼠标或按键。
2. 选择坐姿、站姿、倚靠或自定义预设。每个预设独立保存，并不自动判断你的身体姿态。
3. 把手臂放在舒服的位置，将手保持在镜头内，点击「当前手位设为中心」。以食指指尖为定位点，该位置对应屏幕中心。
4. 调整水平与垂直灵敏度。数值越高，手部移动同样距离，光标走得越远；无需手动拖动映射矩形。预览中的虚线框表示移动到屏幕边缘所需的大致食指指尖活动范围。
5. 调整响应速度：低值更平稳，高值更跟手。

也可点击对应的「手势调节」，用拇指和食指捏合后拖动。两个方向的灵敏度均通过左右拖动调节；响应速度通过上下拖动调节。松开时数值保持，可以换个起始位置再捏合。点击「完成调整」保存；停止预览或关闭窗口也会保存本次调整。调整期间不会向系统输出按键或移动鼠标。

## 模式和操作映射

鼠标模式只在食指和中指伸直并拢时移动光标，定位点为食指指尖。保持约 100 毫秒后开始移动，松开、捏合其他手指或丢失手部时立即停止；移动手势不会触发点击。PPT、媒体和自定义模式只输出你绑定的操作，不会跟着手腕移动光标。

| 模式 | 默认示例 |
| --- | --- |
| 鼠标 | 食指+中指伸直并拢：移动；拇指+食指：左键 |
| PPT | 拇指+食指：下一页；拇指+中指：上一页；拇指+无名指：F5；拇指+小指：Esc；剪刀手：B 黑屏 |
| 媒体 | 拇指+食指：播放/暂停；拇指+中指：下一首；拇指+无名指：音量增加；拇指+小指：音量减小；握拳：静音 |
| 自定义 | 初始为空，可自行绑定 |

下拉菜单支持鼠标操作和常用单键。选择「录制快捷键…」后按下目标键，如 Ctrl+Shift+P；Esc 取消录制，F8 保留为紧急暂停。如果要映射 Esc，直接在下拉菜单选择「退出 Esc」。组合键最多 5 个按键，不执行终端命令或脚本。

匹配手势后需保持默认 200 毫秒，触发一次后松开回到未绑定的手型至少约 120 毫秒再重新触发。长时间保持捏合不会持续翻页或滚动。「识别参数」中可调整保持时间与按手掌宽度归一化的捏合阈值。

键盘操作发送给当前前台窗口：点击「启用控制」后，在 3 秒倒计时内切换到 PPT 或播放器。启用后先放松/松开手势，再开始操作。返回控制台、修改配置、调节灵敏度或录入手势会暂停输出。F8 在摄像头工作时可全局暂停；PyAutoGUI 的屏幕角落紧急停止机制继续保留。

## 录入个人手势

点击「录入自己的手势」，输入名称。2 秒准备时间后，保持一种稳定、单手的静态手型 1.5 秒。成功后，它会出现在所有模式的手势列表中，初始不绑定任何操作；每种模式可独立绑定。删除手势时会删除它在所有模式中的绑定。

目前使用 21 点构成的归一化距离特征匹配，最多 20 个手势；不是重新训练神经网络，不支持动作轨迹。过于相似的手型可能互相匹配，应选差异明显的手型并在预览中确认识别标签。系统只跟踪一只手，避免双手抢占控制。

## CUDA 能做什么

当前 MediaPipe Windows Python 包的手部推理使用 CPU。GUI 的 CUDA 开关只用于 OpenCV 的 BGR→RGB 图像预处理，启用需要带 CUDA/cudaimgproc 的 OpenCV 构建、可用 NVIDIA 设备及兼容驱动。程序不仅检查设备数，还实际上传测试图并运行颜色转换；测试不通过就不能启用。

默认 requirements.txt 安装的是官方 CPU 版 OpenCV，因此这台机器当前显示 CUDA 不可用。CUDA 开关不会安装驱动、编译 OpenCV或改变推理后端；也不保证上传/下载小图像后整体更快。若 CUDA 在运行中报错，控制会停止并显示错误，不会静默声称仍在使用 CUDA。

官方参考：[pywebview 安装](https://pywebview.flowrl.com/guide/installation.html)、[MediaPipe 1.1.1 BaseOptions 的平台限制](https://github.com/google-ai-edge/mediapipe/blob/v1.1.1/mediapipe/tasks/python/core/base_options.py)、[OpenCV CUDA 颜色转换](https://docs.opencv.org/4.x/db/d8c/group__cudaimgproc__color.html)。

## 配置、测试与范围

配置自动保存到仓库根目录的 `user-settings.json`，已加入 gitignore。无效配置会明确提示，使用默认值；再次保存时会先备份原文件为 `user-settings.invalid.json`。启动预览不录制视频，也不把摄像头帧写入日志。

测试命令：`python -m unittest discover -s tests -v`。覆盖姿势预设、灵敏度映射、保持/释放触发、按键校验、组合键释放、录入特征、配置保存、CUDA 能力检测及原有模型适配。另已检查真实 WebView2 桥接和前端交互。测试没有打开真实相机或操作真实 PPT；实际识别效果、不同摄像头与应用的媒体键支持仍需实机确认。
